# Interactive React App Catalog
## Project Overview

An interactive product catalog dashboard built with React and Vite. This project demonstrates React component state, JSX props, reusable components, and hooks lifecycle using `useState` and `useEffect`.
## Features

- Interactive product catalog
- Product search
- Add to Cart functionality
- Dynamic cart count
- Reusable ProductCard component
- React `useState` and `useEffect` hooks
- Responsive design
